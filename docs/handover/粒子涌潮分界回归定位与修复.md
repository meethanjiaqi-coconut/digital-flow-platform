# 粒子涌潮分界回归定位与修复

日期：2026-11-16。用户复现范围：场次开始后的前几个小时。

## 结论

上一轮恢复密度、线宽、拖尾参数，并隔离辅助绘制，修复了拖尾被清空的问题，但没有恢复早期粒子的移动策略。前几个小时涌潮附近的粒子汇聚因此仍然偏弱。

本次找到更早的 `.tmp/water-completion/ParticleFlowLayer.js`，其中第 628 行使用：

```js
const speedScale = bboxArr[2] * 0.045
```

它使粒子在不同视野下保持可辨识的相对运动。后来该式被替换为与水面共用的固定地理尺度：

```js
const speedScale = FLOW_METRES_PER_MODEL_METRE * this._flowStrength / 111320
// 默认值为 600 * 2 / 111320，约 0.01078。
```

以本次对照视野跨度 2.7057 度计算，旧粒子速度系数为 0.12176，是固定系数的约 11.3 倍。粒子寿命仍为 4—10 秒，因此远景中很多粒子尚未汇聚到交界附近便重生。恢复密度与拖尾数值不能补回这一过程。

两个较新的完整备份都已包含固定速度尺度，上一轮只检查它们遗漏了更早的粒子实现。本轮还实际运行了完整备份的构建产物，确认其源码与 source map 一致；随后才继续查找早期文件。

早期文件 SHA-256：`BA027FA968E0E272D63AC5003AEC446CDBB7DD033D9DA005BFF1138FB3AC9E00`。

## 对照试验

固定同一数据、01:22:30 时刻、相机、16,384 个粒子和初始化随机种子 915827；以 1/60 秒步长推进 720 步。比较三种实现：本轮修改前、只恢复视野速度尺度、早期备份。

在 `(120.3966, 30.2925)` 周围 600 米范围，粒子数分别为 **3、41、61**；3 千米范围分别为 **36、235、279**。前两组仅改变速度尺度，说明此项改动确实显著影响交界附近的聚集。早期备份仍有重生和绘制逻辑差异，不能将三组数量视为完全等价。

这些统计用于显示逻辑对照，不是潮头实测位置或含沙量验证。没有另画固定分界线，也没有修改模型流向。

数据包的元数据、网格和 144 个时次，共 146 个文件，与完整备份逐文件 SHA-256 一致；数据包不是本次差异的来源。

## 后续：偶发闪线修复（2026-11-16）

用户反馈粒子偶尔闪烁。固定相机检查 391 帧，检测到 79 次重生后的新旧位置仍落在旧距离阈值内，因而会被当成连续轨迹连接；期间没有相机触发的清屏或全域重播种。随后用实际 GPU 着色器进行单粒子对照，确认这种连接能形成不应出现的亮线。

原条带仅以距离超过视野跨度 2% 判断跳变，存在两个方向的错误：附近重生会误连线；快速连续运动超过阈值则被整条隐藏。现在依据粒子种子是否变化判断重生，只连接同一生命周期的位置；使用现有年龄和寿命实现 0.02—0.18 秒淡入、寿命末尾 0.35 秒淡出。移动速度、4—10 秒寿命、数量和拖尾参数不变。

验证结果：

- GPU 强制附近重生用例：旧着色器产生 25 个亮像素，修复后为 0；连续快速运动用例由误隐藏的 0 像素恢复为 156 像素。这是受控回归用例，不等于所有现场闪烁均来自同一原因。
- 淡入与淡出中点亮度均约为正常值一半，新生起点和寿命终点为零；无 GL 错误。
- 开启水面、4 倍连续播放模型约 01:00—02:59，记录 721 个主视图绘制：没有意外相机清屏或重新分布，无页面、场景或 GL 错误。
- 六组近远景/旋转、播放中缩放、拖尾按钮/滑块和暂停回归通过；`check_particle_controls.mjs`、`check_playback_pause.mjs` 通过。
- 构建成功；独立生产预览确认加载最新 `flow-field-C9SmlqYW.js`。
