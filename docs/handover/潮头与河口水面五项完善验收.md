# 潮头与河口水面五项完善验收

更新：2026-11-16。对应本轮确认的五项整改，延续既有面板、五分钟时间轴及自然水面风格。未开始 SDK 拆分。

## 五项实现

| 项目 | 已完成的处理 |
| --- | --- |
| 1. 潮头跳变 | 保留多个湿水区流向交界候选，按连续时间关联同一个潮头；使用空间容差和传播范围筛除远距离候选。失配先保留一帧弱提示，再取消确定位置。重新识别需连续候选和推进证据，创建新的跟踪段；不同段淡出/淡入，不从旧位置飞越到新位置。 |
| 2. 标记、浪脊、清浊方向统一 | 共用沿河距离与局部上游方向。标记投影到水面使用的距离等值线，并限制在有水网格。移除原固定向西的独立覆盖层，浪脊、白沫直接在水面材质中绘制，沿弯道转向并参与场景遮挡。 |
| 3. 混合带自然化 | 过渡宽度由候选断面跨度与局部流速得到，基础宽度限制在 180～1150 米；叠加沿局部流向拉伸的细丝、卷曲和不规则边缘。采用双相平流，纹理重置时保持连续，避免固定直线或整齐的渐变刷痕。 |
| 4. 潮后浑水演变 | 在模型连通网格上保存浑水历史，由原始 U/V 搬运，配合邻域扩散及指数衰减；仅可信潮头产生新的扰动。失去潮头后，已形成的浑水仍会继续变化。按模型时间推进，暂停冻结，随机跳时与顺序播放结果相同。 |
| 5. 近景水面与倒影 | 增加不重复周期的第三层法线采样，减轻重复纹理；加入窄浪脊、断续白沫和约 12 厘米的潮头几何起伏，保留原微浪与岸线羽化。倒影增加深度边界保护的三点采样，减少岸边采样闪烁；远距离改为渐退，避免直接切断。 |

原模型水位、流速、干湿标记和查询值均未修改。浪脊高度不乘水位夸张倍数。清浊、扩散系数、45 分钟衰减时间尺度、混合带宽度和小幅浪高均属于显示参数，不是新的含沙量或波浪预报。

## 跟踪结果与解释

此前全时段记录中，03:40→03:45 的沿河判识位置变化约 52.5 千米，另有约 45 千米的反向变化。新逻辑不会将这些远距离候选直接连接为同一条运动轨迹。

本场次 144 个时次中，85 个时次形成已关联的跟踪结果，其余为短时弱提示、候选待确认或未确认状态。所有接受的位置都来自当帧实际候选；同一跟踪段、相邻且均已确认的时次之间，最大沿河位置变化为 6213.1 米。这个统计说明异常连接已受到约束，不代表实测传播速度，也不构成潮头位置真值验收。

界面分别显示：

- “清浊示意 · 连续跟踪潮头”：候选可与当前跟踪段连续关联。
- “潮头短时待确认 · 保留弱提示”：一帧失配，弱化提示。
- “潮头候选待确认 · 保留浑水变化”：已有候选，尚未满足重新关联条件。
- “未确认潮头 · 潮后浑水扩散消退”：没有可靠位置，仍有此前形成的浑水。
- “未确认潮头，显示原水色”：既无可靠位置，也无明显残留效果。

旧说明推荐的 03:00 现在属于待确认时段；不再强制保留旧位置。建议先查看 01:10—01:40 的连续推进，随后查看 03:00 的待确认状态和 06:35 的残留消退。

## 历史计算与资源

`tidalEvolution.js` 集中实现候选提取、关联、共享坐标、标记投影与浑水历史。渲染主线程和 Worker 使用同一份算法。

Worker 按时间顺序建立历史，保存判识区的紧凑状态，渲染端只缓存少量节点帧。第一次直接跳到较晚时间会读取之前的模型帧；后续回看使用已有历史。当旧请求正在重建远期历史时，新请求需要的较早帧一旦可用就立即返回，不等待旧请求结束。关闭场次时终止 Worker 并释放资源。

`TidalWaterMix` 将相邻状态同步到水面，`TidalFrontLayer` 仅负责标记。整片水质预设、专题着色与清浊开关仍按原面板规则切换。

## 仍需数据支持的准确性

潮头属于根据现有模型场推断的位置，关联范围与置信处理是工程上的判识约束。没有实测潮头轨迹可用于外部准确度校核，不能据此宣称物理位置全部准确。浑水历史是视觉示意，不代表实测含沙量或沉降率。

倒影仍来自当前屏幕可见场景的颜色和深度，画外/被遮挡区域回退到环境反光。真实河岸建筑倒影需要场景已加载相应三维建筑或倾斜摄影；本次没有虚构这些资产，也没有将卫星影像中的建筑当成三维楼体。

## 2026-11-16 补充：清浊交界梳齿修复

近景复现了交界处重复的细长亮条。原因是将绝对平面坐标按各节点插值后的河道方向旋转，局部方向差放大成纹理坐标的剧烈变化。将旋转临时去掉后，同一时次、同一相机下条纹消失，确认了问题来源。

正式修复位于 `estuaryWaterMaterial.js`：纹理固定在水面坐标中，河道方向只参与最大 60 米的局部扰动；继续按原 U/V 位移搬运。给混合纹理、清浊过渡和细碎泡沫增加像素覆盖范围过滤，减少远景和低俯角下未解析细节的锯齿。保留原水色、法线细浪、反光、潮头判识及浑水历史计算。
