# 河口水面开源方案与接入说明

> 本页保留前两阶段的开源选型与验证历史。其中“未实现”、“随视野换算位移”等描述已被后续整改替代，当前实现和边界见[河口水面整改与验收](河口水面整改与验收.md)。

本次针对“水面像透明蒙版、规则条纹不真实”的反馈，替换自然河口模式的光照和波纹实现。保留现有 SuperMap3D/W3D 网格、原始 5 分钟模型数据、查询、时间轴和粒子系统；不开始 SDK 拆分。

## 已接入实现

1. 删除上一版规则正弦条纹和波峰白线，使用两张 512×512 水波法线贴图，错相交替采样（当前为 16 个动效秒一周期，默认 2 倍强度下约 8 秒），避免无限拉伸及周期重置跳变。
2. 纹理流向读取每个网格插值后的实际 U/V；小尺度风纹只承担视觉细节。显示尺度和移动速度为地图演示做了放大，不代表实测波高或水体实际位移距离。
3. 多尺度法线、粗糙度、高光和 Fresnel 共同决定明暗。浅水泥沙色至深水灰绿色沿用模型水深映射；水色为风格表达，不能解读为含沙量数据。
4. 天空采用中性日光和云层近似，随观察方向和法线反射。这里没有启用岸边建筑/地形镜面倒影，也不声称是预报时刻的太阳辐照模拟。
5. 修正坐标使用：W3D 的 `v_positionWC` 实际是相机 ENU 局部坐标，真实 ECEF 坐标在 `v_position.xyz`。水纹现在基于真实 ECEF 投影到固定东/北方向，不随相机局部原点漂移。
6. 远近细节使用固定世界尺度的相邻层级交叉淡化，并为法线贴图生成 mipmap；避免原先按相机高度连续拉伸整个 UV。
7. 沿用控制器可暂停时钟。贴图异步加载有平坦法线回退；销毁时释放新增 GPU 纹理，迟到的加载回调不会重新创建纹理。
8. 流速/水位专题色保留原路径。左上标题卡片保持删除，粒子密度与线宽控制仍在面板中。

## 流动速度与方向增强

针对水面效果可以、但流速慢且流向不明显的反馈，本轮保留水色、反光和粗糙度参数，集中调整纹理平流。

- 大、小两层法线改为同一世界空间速度；旋转和频率缩放同时作用于纹理坐标与速度，消除细波和大波互相错向、错速的问题。
- 两个时间相位采样同一种纹理特征，不再在两张不同图案间渐变；相位权重在重置处平滑归零。
- 取消独立固定方向的风纹漂移；粗糙度纹理与法线沿相同模型 U/V 平移，缓流逐渐减慢，零流速静止。
- 增加按当前视野换算的可见位移，使全景、近景都更容易看出流动。仍为动效放大，不能按其位移反推模型 m/s；数据与时间轴播放倍率没有改变。
- 水面表达中的流动强度：默认 2.0 倍，可调 0.5～3.0 倍。只影响自然河口水面的动效。使用累计动效时钟，修改强度改变后续速度，不瞬间跳转纹理相位；暂停继续冻结。
