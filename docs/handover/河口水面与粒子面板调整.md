## 水面动态修正（2026-11-13）

业主反馈上一版水面像透明蒙版，缺少流动感。原因是纹理按近似实际速度平移，在约 90 公里相机高度下位移不足一个可辨识像素，远景衰减又削弱了波纹。

本次改为按视距选择纹理尺度，并用模型 U/V 驱动双相位纹理平流，增加断续波峰亮带、运动中的明暗纹理和法线变化。采用展示用速度增强，保证河口总览仍能看到运动；该速度不代表水体实际位移速度，不改变模型流速、水位或查询值。水面本身不依赖粒子层；暂停同时冻结水面时钟。

验证不再只依靠静态截图：

- 开发版固定在 03:00、关闭粒子，保持模型帧 36 不变，只推进水面动画；选定水面区域的两帧平均亮度差为 3.61491，最大差 26（8 位亮度）。
- 相同视角暂停后，两帧该区域的差值为 0。
- 构建版通过可见控件播放、暂停复验：播放差值 3.36521，暂停差值 0；检查时没有捕获页面运行异常。
- `node tools/check_playback_pause.mjs` 和 `npm.cmd run build:demo` 通过。
- 粒子密度、线宽仍直接可见；左上卡片未恢复。
