# 5 分钟数字流场效果验收说明

交付日期：2026-11-13。范围：接入业主提供的 5 分钟输出、完善现有流场展示，并参照钱塘江工程统一 UI。本轮未开展 SDK 拆包、公共接口重构或服务发布。

## 1. 直接查看

- 双击仓库根目录 `启动5分钟流场.cmd`。若同一演示服务已启动，会直接打开浏览器；否则启动服务并打开页面。
- 演示地址：`http://127.0.0.1:5175/#/`。
- 当前机器已准备依赖和转换数据。默认是三维视图和 2026 年 10 月 25 日的 5 分钟场次。
- 点击右侧“定位流场”恢复河口视角；“上一时次 / 下一时次”按真实 5 分钟输出跳转。
- 播放为展示加速：1 倍约 2 秒推进一个输出间隔，支持 2 / 4 / 8 倍。相邻输出之间平滑过渡；“当前展示时间”允许落在两个输出时刻之间。
- 点击水域查看当前水位、流速、流向及 144 个输出时次的过程线。
- 下拉场次仍可选原来的 72 帧逐时数据。两批数据的日期不同，不能据此作同一次潮过程的精度对比。

## 3. 已完成的页面调整

1. **真实时间轴**：时间标签、点选时刻、曲线横轴均按 Manifest 时间戳计算，去掉固定“帧数等于小时数”的假设。支持 5 分钟和原逐时场次。
2. **播放交互**：支持暂停、倍速、拖动、逐帧和首尾跳转；缓冲时保持上一有效画面与展示时间，快速跳转不被过期响应覆盖。
3. **钱塘江 UI 风格**：采用白色卡片、蓝色标题与短下划线、浅灰分区和底部半透明时间轴；统一面板、图例、查询卡与过程线。显示参数默认折叠，面板可收起。
4. **流场表现**：保留真实水位、流速及方向驱动；默认粒子 16,384 个、线条半宽 1 像素，降低叠加亮度和拖尾密度，减弱专题水面的高光与泡沫，减少水面细节遮挡。
5. **地图演示入口**：默认进入三维，直接定位河口；演示模式去除通用框架导航，保留二三维切换和地图控制。
6. **底图**：原影像地址实测连接关闭，演示使用已验证可返回影像的 [Esri World Imagery 服务](https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer)，页面保留来源署名。可在运行时配置脚本中设置 `window.FLOW_FIELD_BASEMAP_URL` 替换服务地址，需兼容 XYZ 瓦片、CORS 和当前地图投影。影像仍需联网。
7. **构建修复**：显式引入 TDesign 全局样式变量，解决开发环境正常而构建版开关、按钮缺失尺寸与颜色的问题。

## 6. 运行与复查

```powershell
# 在仓库根目录验证数据和调度
node tools/check_5min_flow.mjs
node tools/check_playback_pause.mjs

# 在 tdesign 目录运行演示
npm.cmd run dev:demo -- --host 127.0.0.1 --port 5175 --strictPort --open

# 在 tdesign 目录构建与预览
npm.cmd run build:demo
npm.cmd run preview:demo -- --port 5176
```

本地演示的 API 由 Vite 插件提供，`dev:demo` 和 `preview:demo` 均可运行；**直接把 dist 放进静态服务器不会自动提供流场 API**。本轮交付是当前工作区可运行效果，未发布到生产服务器。转换包和原逐时二进制按原仓库规则不纳入 Git，复制工程到其他机器时需要一并携带。

重新转换时，先解压 `data.tar.gz`，准备 Python 与 `tools/requirements-flowfield.txt` 依赖，然后在根目录执行：

```powershell
python tools/preprocess_flowfield.py convert --dat-dir .tmp/flowfield-5min-source --output output/flowfield-5min-20261025 --source-run-id RST-WUV-20261025-5MIN --scenario-name "2026年10月25日 · 5分钟流场" --model-version "qiantang-5min" --time-step-minutes 5 --verify-source --verify-samples 24
```

已存在的输出目录不会默认覆盖；如需重转，应先确认目标目录并按脚本说明处理。当前交付已有转换包，无需重新转换。
