# 河口水面整改与验收

更新：2026-11-15。保留已认可的自然水色、反光、面板和五分钟时间轴；本次完成效果整改，未开始 SDK 拆分。

## 已完成的整改

| 问题 | 现在的处理 |
| --- | --- |
| 水面与粒子速度规则不一致 | 共用线性的 U/V 视觉倍率和流动强度，取消粒子随视野宽度变速。查询值仍是模型 m/s，画面位移有视觉放大。 |
| 退水突然消失 | 干湿两端对称插值透明度；一端变干时保持另一端有效水位，避免消失过程中顶点跌到零高程。 |
| 换向、变速导致水纹跳动 | 积分累计节点位移；修改流动强度只改变后续位移。两个纹理相位仅在各自权重为零时重置，限制长期拉伸。 |
| 缩放改变既有水纹位置 | 位移以米累计，与相机高度无关；缩放仅切换纹理细节。水位顶点直接沿椭球法向抬升，移除原引擎近景相机平面与远景球面之间的几何切换。 |
| 整数时次暂停仍反复上传纹理 | 相同比例直接复用纹理，暂停不更新位移纹理和微浪时钟。 |
| 水陆衔接生硬 | 从模型三角网格边界及干节点计算岸线距离，融合相邻时次岸线；默认约 45 米的视觉渐变带，按屏幕采样适当加宽，上限 90 米。浅水透明度、边缘暗化及近岸波幅衰减共同过渡。该宽度是显示参数，不是实测潮滩宽度。 |
| 缺少场景倒影 | 复制当前场景颜色和不透明物体深度，以屏幕空间射线寻找真实场景交点；倒影随法线波纹扰动，使用深度遮挡保护岸边物体。重新生成着色器后仍更新采样，销毁场次时释放资源。 |
| 没有真实顶点起伏 | 在原网格顶点低位坐标中加入小振幅波高，同时修正水面法线。默认振幅 14 厘米，可调 0～30 厘米；不乘水位夸张倍数，近岸和浅水区衰减，暂停时冻结。 |

面板保留粒子密度、粒子线宽和流动强度。“显示参数”新增“场景倒影”和“微浪振幅（示意）”。左上角旧标题卡片未恢复。

## 数据与效果边界

倒影来自已经加载到三维场景的地形和物体。当前卫星底图中的楼房只是一张影像，不包含楼体几何；本次没有虚构河岸建筑。真实建筑倒影需要接入相应三维模型或倾斜摄影。屏幕之外、被遮挡且没有深度信息的物体，采用天空环境反光回退；这不是全场景离屏镜面反射。

微浪是网格几何与光照的显示效果，受原网格密度约束，不是新增的波浪预报或实测波高。没有将其解释为涌潮破碎浪、岸边拍浪或真实水动力再计算。模型水位、流速、时间序列和查询数据保持原值。

旧五分钟生成目录在本机出现读取权限错误。已从原始 `data.tar.gz` 重建到 `output/flowfield-5min-verified`，转换时执行 24 组 DAT 原始样本核对；随后通过完整包校验。`.env.demo`、`.env.development` 和双击启动入口已指向新目录，没有修改旧目录权限。

## 使用

双击仓库根目录的 `启动5分钟流场.cmd`，或运行 `npm.cmd run dev:demo --prefix tdesign -- --host 127.0.0.1 --port 5175 --strictPort`，打开 `http://127.0.0.1:5175/`。

选择“河口水面”，展开“显示参数”可切换倒影、调节微浪。建议先关闭粒子观察水面本身，再开启粒子核对模型流向。最终视觉认可仍以业主实际查看为准。
