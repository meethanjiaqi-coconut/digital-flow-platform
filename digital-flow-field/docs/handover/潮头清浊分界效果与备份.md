## 已实现的效果

- 同一张水面网格中，潮头前方偏清绿，潮后偏泥沙色；刚经过潮头的区域增加泥沙色层次。
- 中间为带轻微扰动的渐变混合带，跟随当前潮头判识位置推进。沿河距离来自网格连通关系，能沿弯曲河道变化，未采用固定经度或屏幕直线裁切。
- 相邻五分钟输出之间插值潮头位置，始终只有一条主交界，不将两张清浊蒙版交叉淡入。
- 原有水纹、U/V 流动、场景倒影、微浪和近岸羽化继续生效。隐藏“潮头位置”标记时，清浊分界仍可独立显示。
- 没有有效潮头时恢复原水色；出现或消失时平滑改变效果强度。暂停冻结水纹和交界，跳转时间后使用对应帧的潮头。
- 水面帧与潮头帧同步提交，过期请求不能覆盖新时次。关闭水面后跳转，再开启时，旧交界先清除，待对应潮头加载后显示。
- 修复浅水插值造成的条带缺口：模型干湿标记决定覆盖范围，水深只控制近岸透明度。避免“单元有水、节点水深接近零”时把河中水面挖空，未改变模型水位或河床数据。

## 使用

双击仓库根目录的 `启动5分钟流场.cmd`。开发页面为 `http://127.0.0.1:5175/`，本机生产构建预览为 `http://127.0.0.1:5176/`。

右侧选择“水面表达 → 河口水面”，开启“潮头清浊分界”（默认开启）。下方图例分别表示“潮前较清 / 混合带 / 潮后较浑”。可先关闭粒子观察水面交界，再打开“潮头位置”核对位置。2026-10-25 03:00 附近可看到清晰分界；01:10—01:40 可观察交界推进。

关闭该开关恢复原有自然水色。原“水质效果（预设）”仍保留；选择整片水面的水质预设时会关闭清浊分区，避免两种配色叠加。将预设设为“关闭”后，可重新开启“潮头清浊分界”。流速、水位着色继续独立显示。

## 实现入口

| 文件 | 职责 |
| --- | --- |
| `tdesign/src/flowfield/tidal-front-analysis.js` | 提取共享沿河连通与距离计算，原潮头判识规则保持不变。 |
| `tdesign/src/flowfield/tidalWaterMix.js` | 节点沿河坐标、潮头核心强度加权位置、相邻时次位置插值与无潮头回退。 |
| `tdesign/src/flowfield/W3dWaterSurfaceLayer.js` | 清浊开关、沿河坐标纹理、潮头参数、资源释放。 |
| `tdesign/src/flowfield/estuaryVertexShader.js`、`estuaryWaterMaterial.js` | 沿河坐标插值、清/浊水色、混合带扰动、潮后泥沙层次；沿用既有光照和岸边效果。 |
| `tdesign/src/flowfield/FlowFieldController.js` | 水面与潮头原子换帧、快速跳转过期结果保护、隐藏后恢复。 |
| `tdesign/src/flowfield/components/ControlPanel.vue`、`views/flow-field.vue` | 开关、图例、状态同步及与整片水质预设互斥。 |

混合带宽约 850 米，边界扰动约 ±100 米，潮后增强带中心在交界后约 1.2 千米。这些是可见性设计参数，不是模型计算出的真实泥沙锋面尺度。外湾未分类区域逐渐恢复原材质。

## 数据含义

潮头位置复用当前工程根据水位变化、流向与网格关系判识的结果；本次未重新计算水动力，也未新增观测潮头数据。颜色表示相对清浊的视觉示意，不是含沙量、盐度或水质等级计算结果。其空间准确度仍取决于现有潮头判识与原始网格，不能把显示效果当作实测泥沙分布。模型水位、流速、时间轴与查询数值保持原值。
