## 尚需在钱塘江实际环境确认

以下内容依赖目标服务器和平台配置，本机无法代替现场验收：

1. 钱塘江 PostgreSQL 的连接、DDL 权限、备份策略和容量告警。
2. Portainer Stack、宿主机 SSD 挂载和容器重启策略。
3. 现有 9091 nginx 配置、内网防火墙和河口院发布机白名单。
4. 目标 Nacos 的 Namespace ID、Group、Data ID、profile 和账号权限；首次联调可保持关闭。
5. 第 101 场归档、50 用户并发和长时间稳定性压测。
6. 正式生产上线前的平台依赖漏洞扫描与安全审批。当前 Spring Boot/Cloud 版本按既定 Java 8 微服务基线交付，属于联调包，不替代正式安全放行。
